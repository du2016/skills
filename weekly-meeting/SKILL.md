# 周会协作助手

支持两个工作流：
- A. 周会文档创建/初始化
- B. 周会日程创建/会议室预约

## 默认行为（强制）

- 每次触发本 skill，默认按顺序自动执行 A + B，两者都要执行。
- 仅当用户明确说“只创建文档”或“只约会议”时，才执行单工作流。
- B 的默认时间与 A 的目标周绑定：目标周的周五 `15:00-16:00`（`Asia/Shanghai`）。

## 工作流 A：周会文档创建/初始化

### 目标输出

- 文档标题：`<年份>年第<周数>周`（示例：`2026年第24周`）。
- 文档正文：按参会人输出三级标题，每人下方包含两个四级标题：`本周工作`、`下周计划`。
- 格式规则：
  - `本周工作` 后保留 1 行空行。
  - `下周计划` 后保留 3 行空行。

### 空行实现（强制）

- 钉钉会折叠纯 Markdown 空行；不能只依赖连续空行来“留白”。
- 必须用“空白段落”实现留白：在留空行位置写入只包含 `U+200B`（零宽空格）的段落行。
- 数量规则：
  - `本周工作` 后插入 1 个 `U+200B` 段落。
  - `下周计划` 后插入 3 个 `U+200B` 段落。
- 生成 Markdown 时可用 `\u200B` 构造字符，但最终发给 `update_document` 的必须是真实 `U+200B` 字符，不是字面量 `\u200B`。

### 执行流程

1. 确认目标目录。
2. 计算“本周标题”。
3. 创建空文档并重命名为周标题。
4. 按模板覆盖写入正文。
5. 复核标题和正文格式。

### 钉钉工具路由

- `list_nodes`: 逐级定位目录（如 `团队文件/云平台/工程效能/周会/<年份>`）。
- `create_document`: 在目标目录创建空文档。
- `rename_document`: 将文档名设置为 `<年份>年第<周数>周`。
- `update_document`（`mode=overwrite`, `format=markdown`）：一次性写入模板正文。

- 仅当用户指定了其他年份或路径时，再退回 `list_nodes` 逐级定位。

### 周标题规则

- 标题格式固定：`<年份>年第<周数>周`。
- 周数建议用 ISO 周（两位数字可带前导 0，也可不带；保持与用户示例一致即可）。
- 如果用户显式给出周数或标题，优先使用用户给定值。

### 可变项

- 参会人：用户给出名单时，按用户名单替换默认三人。
- 目录：用户给出新路径时，按新路径创建。
- 写入策略：默认 `overwrite`；仅当用户明确要求“保留原文”时使用 `append`。
- 马立虎不写入周会文档（仅用于日程可选参会人）。

### 交付检查清单

- 标题是否为 `YYYY年第WW周`。
- 是否每位参会人均包含 `本周工作` 与 `下周计划` 两个四级标题。
- 是否满足空行规则：两个四级标题后各 1 行空行；每位参会人段尾 3 行空行。
- 如需严谨校验：用 `list_document_blocks` 检查对应位置是否生成 `paragraph` 块（而非被折叠）。

## 工作流 B：周会日程创建/会议室预约

### 输入要素

- 时间范围：支持相对时间表达（如“今天下午2-3点”）。
- 会议室关键词：如“首尔会议室”。
- 时区：默认 `Asia/Shanghai`。

### 默认参数（未显式指定时）

- 日程标题：固定 `devops周会`
- 时间：目标周周五 `15:00-16:00`
- 主会议室：`BJ-F219-首尔`
- 备选会议室：`BJ-F202-塞浦路斯`（同音/口误别名：`塞鲁普斯`）
- 默认必选参会人：`陈世伟`、`相帅`、`赵盼`
- 默认可选参会人：`马立虎`
- 默认 `attendees`（必选）：`["No.1263","No.733","No.212"]`
- 默认可选参会人 ID：`No.072`

### 默认参会人映射（已配置）

- `陈世伟 -> No.1263`
- `相帅 -> No.733`
- `赵盼 -> No.212`
- `马立虎 -> No.072`（默认可选参会人，仅用于日程）

### 参会人规则（强制）

1. 用户明确给了参会名单：按用户名单创建/覆盖参会人。
2. 用户未给参会名单：默认使用必选参会人 `陈世伟`、`相帅`、`赵盼`，并传 `attendees=["No.1263","No.733","No.212"]`。
3. 创建日程时必须传参会人字段：优先 `attendees`（userId 列表），或 `openDingTalkIds`。
4. 马立虎（`No.072`）默认作为可选参会人添加：创建日程后调用 `add_calendar_participant(optional=true)` 补加。
5. 若用户新增其他参会人且未提供可用 ID，再向用户补充索取该人的 `userId/openDingTalkId`。

### 固定会议室 ID（已定位）

- `BJ-F219-首尔`：`557961b49978e2372e3d85e560f7e51403c21c5b80f39c72`
- `BJ-F202-塞浦路斯`：`47aa9b01d2cd82341494360fd44ef59a03c21c5b80f39c72`

### 执行流程（按顺序）

1. 将相对时间转为绝对时间（例如“今天”转成当前日期）。
2. 若用户未给时间，则以 A 产出的目标周计算“周五 15:00-16:00”。
3. 生成毫秒时间戳（`startTime` / `endTime`）。
4. 优先使用固定 `roomId`，先检查主备会议室忙闲：`query_busy_status(startTime,endTime,roomIds=[主,备])`。
5. 选房规则：
   - 主会议室空闲：使用主会议室（首尔）。
   - 主会议室忙、备选空闲：切到备选（塞浦路斯）。
   - 主备都忙：返回冲突并提示换时间。
6. 调用 `create_calendar_event` 创建日程并预约会议室，最少传：
   - `summary`（固定值：`devops周会`）
   - `startDateTime`
   - `endDateTime`
   - `timeZone`
   - `attendees` 或 `openDingTalkIds`（默认必选值：`["No.1263","No.733","No.212"]`）
   - `roomIds`（单元素，取选中的会议室 ID）
   - `location`
7. 调用 `add_calendar_participant` 将 `No.072` 作为可选参会人补加到该日程（`optional=true`）。
8. 返回创建结果：标题、时间、会议室、日程 ID（`id`），并说明马立虎为可选参会人。

- 会议室定位：`BJ-F219-首尔`，`roomId=557961b49978e2372e3d85e560f7e51403c21c5b80f39c72`
- 创建时标题：`devops周会`

### 失败与回退

- 若主备都不可用：明确说明“周五 15:00-16:00 主备会议室都忙”，并建议可选时间段。
- 若会议室 ID 失效：退回 `query_available_meeting_room + list_meeting_room_groups` 重新发现会议室后再创建。

### 接口限制说明

- 当前 `create_calendar_event` 接口无“关闭自动视频会议”参数，创建后通常会返回 `onlineMeetingInfo`。
